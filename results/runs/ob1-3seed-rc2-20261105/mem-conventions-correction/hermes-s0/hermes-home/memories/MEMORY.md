Repo conventions (tally expense CLI, argparse + unittest, git repo): new public functions need docstrings starting with an imperative verb; every change ships tests in tests/test_<module>.py using plain unittest (no pytest); Commit messages follow Conventional Commits, '<type>: <summary>', type one of feat, fix, docs, refactor, test, chore, all lowercase. The '<area>: <summary>' form is retired.; CHANGELOG.md is written by release tooling and must not be edited.
