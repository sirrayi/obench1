All tests pass (`python3 -m unittest discover -s tests`). Python is 3.9, so no newer syntax is used.

Two interpretation choices worth knowing before acceptance:
- A standalone full date (`2026-10-01`) is accepted as a one-day span.
- Month/week/year terms are allowed as endpoints of `A..B`, not just bare ISO dates.
