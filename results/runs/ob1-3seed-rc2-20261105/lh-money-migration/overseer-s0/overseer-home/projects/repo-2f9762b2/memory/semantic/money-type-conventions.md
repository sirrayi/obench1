Money amounts in package code are exact end to end: `Money`/`Decimal`, never float intermediates in text, JSON or CSV. Sum with `Money.sum`; former float-tolerant comparisons are exact. JSON money passes through `to_json()` after rounding; CSV cells format from the Decimal. Each package applies its own rounding mode (payouts: `ROUND_HALF_EVEN`). Rate tables hold `Decimal('…')` literals generated by `gen_rates.py` from the source CSV.
